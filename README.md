# Niyousha Raeesinejad

Personal portfolio site built with React, TypeScript, Material UI, and Vite.

## Scripts

In the project directory, you can run:

### `npm start` / `npm run dev`

Runs the app in development mode. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### `npm run build`

Type-checks the project and creates a production build in the `dist` folder.

### `npm run preview`

Serves the production build locally.

### `npm run typecheck`

Runs the TypeScript compiler without emitting files.
